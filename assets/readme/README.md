# README artwork

Original SVG decorations for this project page, following the ink blue, ice blue,
cream, and coral visual direction of [AstraDraw](https://github.com/IamJerryXu/AstraDraw).
The small cube and trajectory motifs are decorative, not model outputs.

Navigation and section lettering use Comic Neue Bold by Craig Rozynski and Hrant Papazian (SIL Open
Font License 1.1), converted to vector outlines so it displays consistently.
Font source: https://github.com/google/fonts/tree/main/ofl/comicneue.

The title uses Georgia Bold with Trebuchet MS supporting text, rendered to outlines
from locally installed fonts. Font files are not distributed. Its multi-view cameras,
spatial grid, and track markers illustrate the research theme, not measured outputs.

The InkMind.AI mark above the title is the user-supplied original logo, embedded
without redrawing, recoloring, or changing its proportions. It is not a reusable
workflow icon; rights to the mark remain with its owner.

The method diagram, dialogue comparison, and MP4 demo in the parent directory
come from the authors' public repository:
https://github.com/mikubaka88/LMM-Track4D.
Scientific figures are preserved as supplied; these decorative assets do not
alter or add experimental results.
